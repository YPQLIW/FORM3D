# FORM3D Phase 4 결과 보고: 통합 AI 시스템 (v0.4.0)

## 1. 구현한 기능
**AI 제공자 3종** (공통 인터페이스는 `backend/app/ai/base.py`, 각 제공자는 `providers/`)
| 제공자 | 구분 | 지원 기능 |
| --- | --- | --- |
| Claude | 유료 API | 기존 연결 유지, 모델 선택(Opus/Sonnet/Haiku 5.5) |
| Qwen API (DashScope) | 유료 API | 키 등록·변경·삭제, 지역(국제판/중국판), 모델 목록·선택, 연결 테스트, 사용량·예상 비용 |
| Qwen Local (Ollama) | 무료 · 내 PC | 서버 탐지, 설치 모델 목록, 모델 내려받기(진행률·취소), 연결 테스트, 인터넷 없이 사용 |

**통합 AI 관리** (`ai/manager.py`)
- 기본 모델을 정하고, 작업 종류별(AI Assistant / 온이 요청)로 다른 모델을 지정할 수 있습니다.
- 연결에 실패하면 다른 모델로 넘어가는 자동 대체 기능이 있습니다. 기본값은 꺼짐이고, 넘어가면 화면에 표시합니다.
- 모델별 설정: 창의성, 최대 길이, 시간 제한, 기억할 대화 수
- 작은 모델이 형식에 맞지 않는 응답을 내면 1회 다시 요청합니다. 그래도 안 되면 원인과 해결 방법을 표시합니다.
- 사용량과 예상 비용을 SQLite에 기록합니다. 단가표는 화면에서 고칠 수 있고, 로컬 모델은 0원으로 계산합니다.
- 키는 `문서\FORM3D\secrets.json`에만 저장되고 화면에는 가린 값만 보입니다. 기존 `backend/.env`의 키도 계속 인식합니다.

**AI Assistant 확장**
- 이전 대화와 실행 결과(성공/실패/취소)를 기억해서 "그거 빨갛게" 같은 요청을 이해합니다. "새 대화" 버튼으로 맥락을 지울 수 있습니다.
- 응답 종류는 네 가지입니다: 계획(미리보기 → 실행), 되묻기(선택지 버튼), 답변(실행 없음), 거절(이유와 대안).
- 실패한 작업에는 "AI에게 수정 요청" 버튼이 나타나 원인을 반영한 새 계획을 받을 수 있습니다.
- 카드마다 사용한 모델, 토큰 수, 예상 비용(또는 "무료"), 응답 시간을 표시합니다.

**크리에이티브 엔진 구조** (`engines/`)
- 공통 인터페이스: check / submit / status / result / cancel
- 3D 모델·이미지·애니메이션·동영상 엔진을 각각 독립 폴더로 두었습니다.
- 실제로 연결된 엔진은 아직 없으며, 모두 "준비 안 됨"으로 표시합니다.

**온이 연동 확장** (기존 API는 그대로 유지)
- `GET /api/v1/ai/models`: 사용할 수 있는 모델과 상태 (키는 포함하지 않음)
- `POST /api/v1/assist`: 자연어로 작업을 요청하면 AI가 계획하고, 편집기 정책(거부/확인/자동)에 따라 실행합니다.
  - 되묻기나 답변이 나오면 실행하지 않고 그대로 돌려줍니다.
  - `wait:false`로 보내면 작업 ID를 바로 받습니다.
- `GET /api/v1/jobs/{id}`: 진행 상태를 조회합니다 (계획 중 → 확인 대기 → 실행 중 → 완료/실패/취소).
- `POST /api/v1/jobs`에 `wait:false`(비동기) 옵션을 추가했습니다.

**AI 설정 화면** (위쪽 ⚙ AI 설정)
- 탭 구성: AI 제공자, 기본·작업별 모델, 사용량·비용, 크리에이티브 엔진, 온이 연결
- 모든 제공자에 유료/무료 표시를 붙였습니다.

**실제로 확인하지 못한 것:** 이 환경에는 Claude·DashScope 키와 실제 Ollama가 없습니다.
- Claude와 DashScope는 요청 형식, 오류 처리, 비용 계산을 모의 서버로 검증했습니다.
- Ollama는 같은 API를 흉내 내는 가짜 서버로 전체 화면 흐름을 검증했습니다.
- 실제 키와 실제 모델로 응답 품질을 보는 일은 사용자 PC에서 확인해야 합니다.

## 3. 구현하지 않은 것
- 실제 생성 엔진 연결 (이번 지시대로 구조만 만들었습니다)
- 실제 청구 금액 조회 (각 회사 콘솔 API가 별도이며, 화면에는 "예상 비용"으로만 표시합니다)
- 대화 기록 요약 (지금은 최근 N개만 보냅니다)
- 자동 대체 순서를 끌어서 바꾸는 화면 (현재 고정 순서: Ollama → Qwen API → Claude)
- 온이 토큰 발급·폐기 화면

## 4. 설치 조건
- 새 Python 라이브러리 `httpx` 1개가 늘었습니다. `npm run setup`을 한 번 다시 실행하면 됩니다.
- Ollama를 쓰려면 https://ollama.com/download 에서 설치합니다. 권장 사양은 qwen3:8b 기준 그래픽 메모리 8GB입니다(사용설명서 15장).
- DashScope 키는 Alibaba Cloud Model Studio에서 발급합니다. 키를 발급한 지역과 같은 지역을 선택해야 합니다.
