# FORM3D Phase 3 결과 보고 — 프로젝트 관리 시스템 · AI Assistant 기반 (v0.3.0)

## 1. 구현한 기능
### 프로젝트 저장 시스템
- `.form3d` 형식(ZIP): `manifest.json`(형식·버전·통계) · `scene.glb`(오브젝트·그룹·Transform·재질·색·텍스처·숨김·애니메이션, 표준 glTF) · `project.json`(카메라·설정) · `thumbnail.png`
- 새 프로젝트 / 이름 변경 / 저장(Ctrl+S) / 다른 이름으로 저장(Ctrl+Shift+S) / 열기 / 최근 목록(미리보기) / 버전 기록(덮어쓰기 전 자동 보관, 최근 10개)
- 자동 저장(2분, 저장소 프로젝트) + 복구용 기록(30초, 브라우저 IndexedDB) + 시작 시 복구 창
- 저장 안 된 변경 표시(주황 점, 창 제목 ●, 상태줄, 닫기 경고), 화면 안 확인 대화상자
- 로컬 서버(Python FastAPI + SQLite, 127.0.0.1:8765): 원자적 쓰기(임시 파일→fsync→교체), 파일 검증(ZIP·형식·버전·손상), 용량 제한
- 서버 없이도: `.form3d` 내려받기/열기, 복구 기록, 규칙 기반 해석기 동작. GLB 내보내기는 별도 기능으로 유지

### AI Assistant · 명령 구조
- 흐름: 문장 → 해석(AI 연결부 또는 규칙 기반 해석기) → JSON 작업(고유 ID) → 검증 → 미리보기 → [실행]/[취소] → 결과 → Ctrl+Z 1회로 되돌리기
- 명령 표준 `commands.json` 하나를 편집기(TS)·서버(Python)가 공유, 두 곳에서 검증. 목록 밖 명령·파라미터는 이유와 함께 거부, 코드 실행 경로 없음
- 다단계 작업(최대 30단계), 실패 시 전체 롤백, `created` 대상으로 앞 단계 결과 이어 쓰기
- AI 연결부: Claude(`claude-opus-5-5`, structured outputs), 키는 `backend/.env`에만, 미연결 시 "연결 안 됨"으로 정직하게 표시하고 규칙 기반(“AI 아님” 표시)만 사용

### 온이(외부 AI) 연동 기반
- `/api/v1`: capabilities · project · scene · projects · jobs · objects(생성/수정/삭제) · engines
- Bearer 토큰(해시 저장) + 권한(scope), 로컬 전용(loopback·Host·Origin 검사), 편집기 정책(거부/확인 후 실행/자동 실행)
- 엔진 레지스트리(이미지·애니메이션·영상·3D): 구조만, 모두 "사용 불가"로 응답 (구현 안 함)

## 3. 구현하지 않은 기능
- 실제 Claude 호출 검증(키 등록 후 사용자 환경에서 확인 필요), AI 대화 맥락 유지(이전 대화 기억)
- 프로젝트 삭제, 저장소 폴더 변경 화면(현재는 `.env`의 FORM3D_DATA_DIR), 토큰 발급/폐기 화면
- 여러 편집기 창 동시 사용(마지막 창만 외부 명령 수신, 복구 기록 1개 공유)
- 이미지·영상·애니메이션 생성(지시대로 구조만)
- Phase 2 미완성 목록(사각형 선택, 직교 카메라 등)은 그대로

## 4. 온이 연동에 필요한 것
1. 온이가 `oni-token.txt` 토큰을 읽어 `Authorization: Bearer` 헤더로 호출
2. `GET /api/v1/capabilities`로 명령 목록을 받아 온이의 도구(tool) 정의로 사용
3. 편집 요청은 `POST /api/v1/jobs` 하나로 통일 권장, 결과 `status`/`message`를 사용자에게 전달
4. 온이가 같은 PC에서 실행되어야 함(원격이면 별도 보안 터널·인증 설계 필요)
5. 자세한 형식: `docs/ONI-API.md`
