# FORM3D Phase 4.5 결과 보고: 대화형 AI Assistant (v0.4.5)

## 결론
- FORM3D 쪽 경로는 모두 만들었고, 모의 Qwen 서버로 지시서의 8가지 시나리오를 검증했습니다.
  - 대화 기록 전달, 방금 만든 오브젝트 기억, 장면 정보 전달
  - 되묻기, 미리보기 → 실행 → Undo
  - 온이 연결, 오류 안내
- **실제 Qwen 모델로는 아직 확인하지 못했습니다.** 이 작업 환경에는 Qwen 키가 없습니다. 그래서 이번 단계를 "완성"이라고 하지 않습니다. 실제 키로 확인한 뒤 완성으로 보고하겠습니다. 확인 방법은 아래 4장에 있습니다.

## 1. Qwen 연결 수정
| 문제 | 수정 |
| --- | --- |
| qwen3 계열 모델이 400 오류를 냄 (비스트리밍 요청에 `enable_thinking: false`가 필요함) | 모든 요청에 `enable_thinking: false`를 보냅니다. 생각 전용·이미지·음성 모델(qwq, \*-thinking, -vl 등)은 모델 목록에서 뺐습니다 |
| 대기 시간이 짧음 | 기본값을 120초에서 180초로 늘렸습니다. 예전 기본값 120초로 저장된 설정도 180초로 올립니다. 최대 600초까지 바꿀 수 있습니다 |
| 기다리는 동안 아무 표시가 없음 | 경과 시간(초)과 **취소** 버튼을 표시합니다 |
| 오류 원인이 불분명 | 다음 경우를 구분해서 안내하고, 서버가 보낸 원래 오류 문장도 함께 보여 줍니다.<br>• 키 오류 또는 지역 불일치 (현재 지역 표시)<br>• 모델 미지원<br>• 권한 없음 (403)<br>• 연결 불가<br>• 시간 초과<br>• FORM3D 로컬 서버 꺼짐 |

## 2. 대화형 비서 기능
- **방금 만든 것 기억:**
  - 실행 결과에 만든 오브젝트의 id를 남깁니다.
  - 장면 정보에도 `recentlyCreated`를 함께 보냅니다.
  - 그래서 "조금 더 크게"는 `{ids:[…]}, scale_by 1.25`가 됩니다.
- **AI가 한 말 표시:**
  - 계획 카드 위에 AI의 말("원기둥을 하나 만들겠습니다.")을 보라색으로 보여 줍니다.
  - 실제 실행 결과는 편집기가 만든 초록색 문장입니다.
  - 규칙 기반 카드에는 "AI 아님"이라고 표시합니다.
- **AI 지시문 보강:**
  - 일반 대화에 답하기
  - 장면 질문에 실제 이름·개수·색으로 답하기
  - "조금 더 크게"는 1.25배, "조금 작게"는 0.8배 등 상대적인 말 해석
  - 단순한 요청은 묻지 않고 바로 계획
  - 대상이 모호하거나 여러 개를 삭제하는 요청은 먼저 묻기
- **이미 있던 기능 그대로 사용:**
  - 명령 16종, 검증, 미리보기, 실행 승인, Undo, 되묻기 선택지, 실패 시 "AI에게 수정 요청"
  - 새 명령이나 새 AI 제공자는 추가하지 않았습니다.

## 3. 온이 연결
- `/api/v1/assist`에 같은 `conversation`을 보내면 이전 요청과 실행 결과를 기억합니다. 예를 들어 "그거 오른쪽으로 옮겨줘"가 됩니다.
- 응답에 다음이 포함됩니다: `conversation`, `plan.message`(AI의 말), `result.created`(만든 오브젝트의 id·이름).
- 현재 장면은 `GET /api/v1/scene`으로 확인합니다.
- 토큰, 권한, 편집기 정책(거부/확인/자동)은 그대로입니다.

## 5. 업데이트 방법
1. zip을 풀어 기존 폴더에 덮어씁니다.
2. `npm install`을 실행합니다.
3. `npm run dev`를 실행합니다.

새 라이브러리가 없어서 `npm run setup`은 다시 하지 않아도 됩니다.
