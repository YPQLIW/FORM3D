## 0. 설치하고 실행하기 (설치형 프로그램 · 추천)

### 처음 한 번만
1. https://github.com/YPQLIW/FORM3D/releases 에 들어가서 가장 위 버전의 **`FORM3D-Setup-버전.exe`**를 누르면 내려받아집니다.
2. 내려받은 파일을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다. (코드 서명 인증서가 없어서 처음 한 번 뜨는 경고입니다)
3. 설치 위치를 확인하고 **설치**를 누릅니다. 바탕화면과 시작 메뉴에 **FORM3D** 아이콘이 생깁니다.
   - Python, npm, cmd는 필요 없습니다. 프로그램 안에 모두 들어 있습니다.

### 매번 실행할 때
- 바탕화면의 **FORM3D** 아이콘을 더블클릭합니다. 잠시 뒤 편집기 창이 열립니다.
- 끝낼 때는 저장(Ctrl+S)한 뒤 창을 닫으면 됩니다. 서버도 함께 꺼집니다.

### 업데이트
- 새 버전이 나오면 프로그램이 켜질 때 스스로 내려받습니다.
- 다 받으면 **"새 버전이 준비되었습니다 → 지금 다시 시작"** 창이 뜹니다. 누르면 끝입니다.
- **나중에**를 누르면 다음에 창을 닫을 때 자동으로 적용됩니다.

### 알아 두기
- 프로젝트, AI 키, 설정은 **문서\FORM3D** 폴더에 저장됩니다. 예전 방식으로 쓰던 자료도 그대로 이어서 열립니다. 프로그램을 지워도 남습니다.
- 예전 방식(`npm run dev`)으로 켜 둔 cmd 창이 있으면 먼저 닫으세요. 같은 포트를 써서 프로그램이 시작되지 않습니다.
- 문제가 생기면 **문서\FORM3D\logs\server.log** 파일을 보내 주세요.

## 0-1. (개발용) 소스에서 직접 실행하기

### 처음 한 번만
1. 바탕화면의 기존 `FORM3D` 폴더 이름을 `FORM3D-phase2`로 바꿉니다. (백업)
2. `FORM3D-phase3.zip`을 바탕화면에 압축 해제합니다. → `C:\Users\hayul\Desktop\FORM3D` 폴더가 생깁니다.
3. **Python 설치** (프로젝트 저장소·AI 기능용, 처음 한 번)
   - https://www.python.org/downloads/ 에서 노란 **Download Python** 버튼 → 설치 파일 실행
   - 첫 화면 아래쪽 **"Add python.exe to PATH"** 를 꼭 체크 → **Install Now**
4. 명령 프롬프트(cmd)를 **새로** 열고 한 줄씩 입력:
   ```
   cd C:\Users\hayul\Desktop\FORM3D
   npm install
   npm run setup
   ```
   `npm run setup`은 로컬 서버를 설치합니다(1~3분). 마지막에 "로컬 서버 설치 완료!"가 나오면 성공입니다.
5. (선택) **AI 연결**: 실행 후 화면 위쪽 **⚙ AI 설정**에서 합니다. (15장 참고)
   AI가 없어도 **규칙 기반 해석기**(AI 아님)로 기본 명령은 쓸 수 있습니다.

> Phase 3에서 업데이트하는 경우: 새 zip을 풀고 `npm install` → `npm run setup`을 **한 번 다시** 실행하세요. (새 부품 httpx 설치)

### 매번 실행할 때
1. 명령 프롬프트에서:
   ```
   cd C:\Users\hayul\Desktop\FORM3D
   npm run dev
   ```
   로컬 서버와 편집기가 함께 켜집니다. (`[FORM3D] 로컬 서버 시작` 문구 확인)
2. 크롬에서 **http://localhost:5173** 을 엽니다.
3. 오른쪽 아래 상태줄에 **● 서버 연결됨**(초록)이 보이면 저장소·AI·외부 API를 쓸 수 있습니다.
4. 끝낼 때는 저장(Ctrl+S) 후 명령 프롬프트에서 `Ctrl + C`.

> Python 없이도 편집기는 열립니다. 이때 "저장"은 `.form3d` 파일 내려받기로 동작합니다.

## 1. 화면 구성

| 위치 | 이름 | 하는 일 |
| --- | --- | --- |
| 맨 위 | 상단 메뉴 | 실행 취소/다시 실행, **도형 추가**, **모델 불러오기**, **내보내기 (GLB)** |
| 왼쪽 | 씬 목록 (Scene Hierarchy) | 장면에 있는 모든 물체 목록. 선택·이름 변경·그룹·순서 변경 |
| 가운데 | 3D 뷰포트 | 물체를 보고 마우스로 직접 움직이는 곳 |
| 뷰포트 왼쪽 위 | 도구 모음 | 이동/회전/크기 도구, 좌표계, **스냅(자석)**, 선택 모드, **카메라 시점** |
| 오른쪽 | 속성 패널 | 이름, **위치·회전·크기 숫자 입력**, 재질, **정렬/스냅** |
| 아래 | 작업 로그 | 무엇이 성공/실패했는지 알려줌 (문제가 생기면 여기를 먼저 보세요) |

### 뷰포트 마우스 조작
- **왼쪽 버튼 드래그**: 화면 회전
- **오른쪽 버튼 드래그**: 화면 이동
- **휠**: 확대 / 축소
- **클릭**: 물체 선택, 빈 곳 클릭: 선택 해제
- **F**: 선택한 물체로 카메라 맞추기 (아무것도 선택 안 했으면 전체)

## 2. 물체 만들기와 불러오기

### 기본 도형 추가
상단 **도형 추가** → 큐브 / 구 / 원기둥 / 원뿔 / 토러스 / 평면 중 선택.

### 모델 파일 불러오기 (GLB, GLTF, OBJ)
상단 **모델 불러오기** 버튼을 누르거나, 파일을 뷰포트로 **끌어다 놓으면** 됩니다.

| 파일 종류 | 함께 선택할 파일 |
| --- | --- |
| `.glb` | 없음 (한 파일에 다 들어 있음) |
| `.gltf` | 옆에 있는 `.bin`, 텍스처 이미지 |
| `.obj` (Phase 2 신규) | 같은 이름의 `.mtl`(재질), 텍스처 이미지(`.png/.jpg` 등) |

**OBJ를 색·무늬까지 제대로 불러오는 법**
1. 모델 불러오기를 누릅니다.
2. 파일 선택 창에서 `Ctrl`을 누른 채 `.obj`, `.mtl`, 이미지 파일들을 **모두 클릭**합니다.
3. 열기를 누릅니다.

- `.mtl`을 빼먹으면 회색으로 불러오고, 아래 로그에 "재질 파일이 함께 선택되지 않아…"라고 알려줍니다.
- 이미지가 빠지면 어떤 이미지가 없는지 로그에 이름이 나옵니다. 그 파일을 같이 선택해서 다시 불러오세요.

## 3. 선택하기 (여러 개 선택 포함)

| 하고 싶은 것 | 방법 |
| --- | --- |
| 하나 선택 | 뷰포트나 씬 목록에서 클릭 |
| 여러 개 선택 | **Ctrl + 클릭** (또는 Shift + 클릭) |
| 선택에서 하나 빼기 | 선택된 것을 다시 **Ctrl + 클릭** |
| 목록에서 범위로 선택 | 씬 목록에서 첫 항목 클릭 → 마지막 항목 **Shift + 클릭** |
| 전부 선택 | **Ctrl + A** |
| 선택 해제 | **Esc** 또는 빈 곳 클릭 |

- 선택된 물체 주위에 박스가 생깁니다. **보라색 = 마지막에 고른 물체(활성)**, 파란색 = 나머지.
- 불러온 모델에서 일부분(메시)만 고르려면 뷰포트 도구 모음의 **선택 모드를 '메시'(정육면체 아이콘)** 로 바꾸세요.

## 4. 움직이기 · 돌리기 · 크기 바꾸기

### 마우스로 (기즈모)
1. 물체를 선택합니다.
2. 도구를 고릅니다: **W = 이동**, **E = 회전**, **R = 크기**
3. 물체에 나타난 화살표/고리/네모 손잡이를 드래그합니다.
   - 빨강 = X(좌우), 초록 = Y(위아래), 파랑 = Z(앞뒤)
- 드래그하는 동안 화면 위쪽에 **얼마나 움직였는지 숫자로** 보입니다.
- **여러 개를 선택하면** 손잡이가 선택한 물체들의 가운데에 생기고, 모두 함께 움직입니다/돌아갑니다.

### 숫자로 정확하게 (오른쪽 Transform 패널)
- 칸에 숫자를 쓰고 **Enter**. (Esc를 누르면 취소)
- **계산식도 됩니다**: `1.5*2`, `(1+2)/4`, `10-3.5`
- 칸을 클릭한 뒤 **↑ / ↓ 키**: 조금씩 증감 (Shift를 같이 누르면 10배)
- 칸 앞의 **X / Y / Z 글자를 마우스로 좌우로 끌면** 값이 바뀝니다. (Shift를 같이 누르면 더 미세하게)
- 줄 오른쪽 **↺ 버튼**: 위치는 0, 회전은 0, 크기는 1로 초기화
- **크기 비율 고정** 버튼을 켜면 크기 X를 바꿀 때 Y·Z도 같은 비율로 바뀝니다.
- 여러 개를 선택했을 때 값이 서로 다르면 칸에 `—`가 보입니다. 거기에 숫자를 쓰면 **모두 같은 값**이 됩니다.

## 5. 스냅 (딱딱 맞춰 움직이기)

1. 뷰포트 도구 모음의 **자석 아이콘**을 눌러 켭니다 (밝게 표시됨).
2. 자석 옆 **숫자(예: 0.5)** 를 누르면 단위를 바꿀 수 있습니다.
   - 이동 (m): 기본 0.5 → 0.5칸씩 움직임
   - 회전 (°): 기본 15 → 15도씩 돌아감
   - 크기: 기본 0.1
3. 이제 손잡이를 드래그하면 그 단위로만 움직입니다.

- 드래그하는 중에 **Ctrl을 누르고 있으면** 잠깐 반대로 동작합니다. (스냅이 켜져 있으면 잠깐 꺼짐)

## 6. 정렬 (오른쪽 '정렬 / 스냅' 패널)

| 버튼 | 하는 일 | 필요 개수 |
| --- | --- | --- |
| X/Y/Z × 최소·중앙·최대 | 물체들의 왼쪽 끝/가운데/오른쪽 끝(Y는 아래/가운데/위)을 한 줄로 맞춤 | 2개 이상 |
| ↔ (분배) | 양 끝 물체는 그대로 두고, 사이 간격을 똑같이 | 3개 이상 |
| 바닥에 놓기 | 물체 밑면을 바닥(Y=0)에 딱 붙임 | 1개 이상 |
| 그리드 스냅 | 위치를 스냅 단위에 맞게 반올림 | 1개 이상 |

- **기준**: '선택 영역 전체' = 고른 물체들 전체를 기준 / '활성 오브젝트' = 마지막에 고른 물체(보라색)에 나머지를 맞춤
- 예) 바닥에 물체 3개를 일렬로 세우기: 3개 선택 → **바닥에 놓기** → **Z 중앙** → **X ↔(분배)**

## 7. 복제 · 그룹 · 삭제

| 하고 싶은 것 | 단축키 | 다른 방법 |
| --- | --- | --- |
| 복제 | **Ctrl + D** | 씬 목록 위 복사 아이콘, 우클릭 → 복제 |
| 그룹으로 묶기 | **Ctrl + G** | 씬 목록 위 그룹 아이콘, 우클릭 메뉴 |
| 그룹 풀기 | **Ctrl + Shift + G** | 씬 목록 위 그룹 해제 아이콘, 우클릭 메뉴 |
| 삭제 | **Delete** | 씬 목록 위 휴지통 아이콘, 우클릭 → 삭제 |

- 복제본은 원본 **오른쪽 옆**에 생기고, 이름은 `Box.001`처럼 번호가 붙습니다. 색을 바꿔도 원본은 그대로입니다.
- 그룹을 만들면 묶인 물체들을 **하나처럼** 움직이고 돌릴 수 있습니다. 그룹을 풀어도 보이는 위치는 그대로입니다.
- 움직이는 애니메이션이 있는 모델(예: 걷는 여우)은 **그룹 해제가 안 되고**, 모델의 일부만 따로 복제할 수도 없습니다. 애니메이션이 깨지지 않게 막은 것이며, 이유가 로그에 나옵니다. 모델 전체 복제는 됩니다.

## 9. 씬 목록(왼쪽) 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 물체를 다른 물체 **안으로** 넣기 (부모-자식) | 항목을 끌어서 다른 항목 **한가운데**에 놓기 (파란 테두리) |
| 순서 바꾸기 | 항목을 끌어서 다른 항목의 **위쪽/아래쪽 가장자리**에 놓기 (파란 선) |
| 밖(최상위)으로 꺼내기 | 목록 아래 **빈 공간**에 놓기, 또는 우클릭 → 최상위로 꺼내기 |

| 찾기 | 위쪽 **'이름으로 검색'** 칸에 입력 |
| 모두 펼치기 / 접기 | 검색칸 오른쪽 두 아이콘 |

| 키보드로 이동 | 목록 클릭 후 **↑↓** 이동, **→** 펼치기, **←** 접기 |
| 메뉴 열기 | 항목 **우클릭** |

- 여러 개를 선택한 상태에서 끌면 한꺼번에 옮겨집니다.
- 옮겨도 화면에서 보이는 위치는 바뀌지 않습니다.

## 11. 프로젝트 저장 · 열기 (Phase 3)

**프로젝트 저장**(.form3d)은 나중에 이어서 작업하기 위한 것이고, **내보내기 (GLB)** 는 결과물을 다른 프로그램에 줄 때 씁니다. 둘은 별개입니다.

### 저장
- **Ctrl + S** 또는 위쪽 **저장** 버튼
  - 처음 저장하면 프로젝트 저장소(`문서\FORM3D` 폴더)에 새로 만들어집니다.
  - 다시 저장하면 덮어쓰고, **바로 전 저장본은 버전 기록으로 자동 보관**됩니다(최근 10개).
- **Ctrl + Shift + S**: 다른 이름으로 저장 (새 이름 입력 → 새 프로젝트로 복사)
- 프로젝트 이름 옆 **주황 점** = 저장 안 된 변경이 있음. 브라우저 탭 제목에도 `●`가 붙습니다.
- 저장 안 하고 창을 닫으려 하면 브라우저가 경고합니다.

### 열기 · 새로 만들기 · 이름 바꾸기
- 왼쪽 **프로젝트** 탭: 최근 프로젝트 목록(미리보기 그림 포함) → **열기**
- 목록의 **이름 바꾸기**, 또는 위쪽 프로젝트 이름을 클릭해 고치고 Enter
- **파일 → 새 프로젝트**
- 저장 안 된 변경이 있으면 "저장 / 저장 안 함 / 취소"를 먼저 물어봅니다.
- 현재 프로젝트 카드의 **버전 기록 보기** → 예전 저장본 **열기** → 마음에 들면 Ctrl+S (그 내용으로 되돌아감)

### 내 컴퓨터 파일로
- **파일 → 내 컴퓨터에 .form3d 파일로 내려받기**: 다운로드 폴더에 저장 (백업·다른 PC로 옮길 때)
- **파일 → 내 컴퓨터의 .form3d 파일 열기**

### 자동 저장과 복구
- 저장 안 된 변경이 있으면 **30초마다 복구용 기록**을 브라우저에 남깁니다.
- 저장소 프로젝트는 **2분마다 자동 저장**됩니다. (파일 메뉴에서 끄고 켤 수 있음)
- 갑자기 꺼졌다면 다시 열 때 **"저장하지 않은 작업이 있습니다"** 창이 뜹니다 → **복구하기** → Ctrl+S.

### 저장되는 내용
오브젝트와 그룹 구조, 위치·회전·크기, 재질·색상, 텍스처, 숨김 상태, 애니메이션, 카메라 위치, 격자·스냅·도구 설정.

## 12. AI Assistant (아래 패널)

1. 아래 **AI Assistant** 탭을 엽니다.
2. 위쪽 **해석기**:
   - **AI**: Claude가 문장을 명령으로 바꿉니다. API 키를 등록해야 켜집니다. 옆에 "AI 연결됨 · 모델 이름"이 보입니다.
   - **규칙 기반**: AI가 아닙니다. 정해진 표현만 이해합니다. (AI가 연결되지 않으면 자동으로 이쪽을 씁니다)
3. 입력창에 예: `큐브 하나 만들어 줘` → Enter
4. **명령 미리보기 카드**가 나옵니다: 작업 ID, 단계별 명령, 출처. 이때는 아직 아무것도 바뀌지 않습니다.
5. **실행**을 누르면 적용되고 결과가 표시됩니다. **취소**를 누르면 아무것도 하지 않습니다.
6. 되돌리기: 카드의 **이 작업 실행 취소** 또는 **Ctrl + Z** (여러 단계도 한 번에 되돌아감).
7. 한 단계라도 실패하면 전체가 취소되고 이유가 표시됩니다. 이해 못 한 문장은 추측하지 않고 안내만 합니다.

규칙 기반으로 되는 예: "큐브 하나 만들어 줘", "선택한 오브젝트를 오른쪽으로 3만큼 이동해 줘", "모든 오브젝트를 선택해 줘", "선택한 물체의 색상을 파란색으로 변경해 줘", "이 오브젝트를 복제해 줘", "선택한 물체들을 하나의 그룹으로 묶어 줘", "모두 위로 2만큼 올린 다음 선택 해제해 줘".

## 15. AI 설정 (Claude · Qwen API · Ollama)

위쪽 **⚙ AI 설정**을 누르면 설정 창이 열립니다. 셋 중 하나만 준비해도 됩니다.

| 방식 | 비용 | 필요한 것 |
| --- | --- | --- |
| Claude | 💳 유료 (쓴 만큼) | Claude API 키 (console.anthropic.com) |
| Qwen API (DashScope) | 💳 유료 (쓴 만큼, 보통 Claude보다 저렴) | Alibaba Cloud Model Studio API 키 |
| Qwen Local (Ollama) | 🖥 무료 · 내 PC | Ollama 설치 + 모델 내려받기 (인터넷 없이 사용 가능) |

### Ollama (무료) 연결하기
1. https://ollama.com/download 에서 Windows용을 내려받아 설치합니다. 설치 후 Ollama가 자동으로 켜집니다.
2. FORM3D **AI 설정 → AI 제공자 → Qwen Local (Ollama)** 카드가 "사용 가능"(초록)으로 바뀝니다.
3. **모델 내려받기** 칸에 `qwen3:8b`를 넣고 **내려받기**를 누릅니다(약 5GB, 한 번만).
   - 그래픽카드가 약하거나 없으면 `qwen3:4b`(약 2.5GB)를 쓰세요.
   - 여유가 있으면 `qwen3:14b`(그래픽 메모리 12GB 이상)가 더 정확합니다.
4. **모델** 목록에서 받은 모델을 고르고 **연결 테스트**를 누릅니다. "연결 성공"이 나오면 완료입니다.
5. **기본·작업별 모델** 탭에서 기본을 Ollama로 정합니다.

### Qwen API / Claude (유료) 연결하기
1. 키 칸에 API 키를 붙여넣고 **저장**합니다. 키는 이 PC의 로컬 서버 파일에만 저장되고, 화면에는 `sk-a…1234`처럼 가려서 보입니다.
2. Qwen API는 **지역**을 키를 발급한 곳(국제판 / 중국판)과 같게 맞춥니다.
3. **모델**을 고르고 **연결 테스트**를 누릅니다. 실패하면 원인과 해결 방법이 표시됩니다.

### 그 밖의 설정
- **기본·작업별 모델:** 기본 모델과, AI Assistant·온이 요청에 각각 쓸 모델을 정합니다. "연결 실패 시 자동 대체"를 켜면 실패할 때 다른 모델로 넘어갑니다. 유료로 넘어갈 수 있으니 주의하세요.
- **사용량·비용:** 모델별 요청 수, 토큰 수, 예상 비용을 봅니다. 단가는 직접 고칠 수 있습니다. 정확한 청구 금액은 각 회사 콘솔에서 확인하세요.
- **크리에이티브 엔진:** 3D·이미지·애니메이션·동영상 생성 엔진의 상태를 봅니다. 지금은 모두 "준비 안 됨"입니다.

### AI Assistant 새 기능
- **대화를 기억합니다:** "구 하나 만들어 줘" → 실행 → "그거 빨갛게 해 줘"처럼 이어서 말할 수 있습니다. 처음부터 다시 하려면 **새 대화**를 누르세요.
- **되묻기:** 요청이 모호하면 AI가 먼저 질문하고 선택지 버튼을 보여 줍니다. 버튼을 누르면 그 답으로 계속합니다.
- **질문에 답변:** "씬에 뭐 있어?"처럼 물으면 아무것도 바꾸지 않고 답만 합니다.
- **실패 복구:** 작업이 실패하면 **AI에게 수정 요청** 버튼으로 고친 계획을 받을 수 있습니다.
- 카드 아래에 사용한 모델, 토큰 수, 예상 비용(또는 "무료"), 응답 시간이 표시됩니다.

### AI와 대화하며 편집하기 (v0.4.5)
AI Assistant는 명령어 입력창이 아니라 대화 상대입니다. 평소 말투로 쓰면 됩니다.

| 이렇게 말하면 | AI가 하는 일 |
| --- | --- |
| "안녕, 넌 뭘 할 수 있어?" | 답만 합니다. 장면은 바꾸지 않습니다 |
| "원기둥 하나 만들어 줘" | "원기둥을 하나 만들겠습니다."라고 말하고 미리보기 카드를 보여 줍니다. **[실행]**을 눌러야 만들어집니다 |
| "조금 더 크게 해줘" | 방금 만든 원기둥을 기억하고 1.25배로 키우는 계획을 보여 줍니다 |
| "지금 장면에 뭐 있어?" | 장면에 있는 오브젝트 이름과 개수를 알려 줍니다 |
| "하나 지워줘" | 어느 것을 지울지 선택지 버튼으로 먼저 묻습니다 |

- 보라색 글씨는 **AI가 한 말**이고, 초록 글씨는 **편집기가 실제로 실행한 결과**입니다.
- "규칙 기반 해석기 · AI 아님"이라고 붙은 카드는 AI가 아닌 기본 해석기가 만든 것입니다.
- AI가 생각하는 동안 **경과 시간**이 보이고, **취소** 버튼으로 멈출 수 있습니다. 이미 보낸 요청은 비용이 청구될 수 있습니다.
- 마음에 들지 않으면 카드의 **이 작업 실행 취소**나 Ctrl+Z로 되돌립니다.

### 모델 바꾸기와 대화 기록 (v0.5.0)
- AI Assistant 위쪽의 **모델** 선택 상자에서 연결된 AI(Ollama·Qwen API·Claude)로 바로 바꿀 수 있습니다. 설정 창을 열 필요가 없습니다.
- 프로그램을 껐다 켜도 **마지막 대화가 다시 보이고**, AI도 그 대화를 기억합니다. 처음부터 하려면 **새 대화**를 누르세요.

### 실제 AI 점검 (v0.5.0)
내 PC에 연결된 실제 AI가 FORM3D에서 제대로 일하는지 버튼 하나로 확인합니다.
1. 위쪽 **⚙ AI 설정** → **실제 AI 점검** 탭을 엽니다.
2. 점검할 모델을 고르고 **점검 시작**을 누릅니다. 로컬 모델은 몇 분 걸릴 수 있습니다.
3. 8가지 항목이 하나씩 ✅ 통과 / ❌ 실패 / ⏭ 건너뜀으로 표시됩니다. 항목을 누르면 AI가 실제로 한 말을 볼 수 있습니다.
   - 일반 질문, 대화 기억, 후속 요청, 되묻기, 복잡한 계획, Claude↔Qwen 전환, Ollama, 온이
4. **보고서 복사**를 눌러 Claude에게 붙여 넣어 주시면, 실제 결과를 보고 고칩니다. 보고서는 **문서\FORM3D\reports**에도 저장됩니다.
- 장면은 바뀌지 않습니다. 유료 모델이면 요청 10회 정도의 비용(몇십 원 이하 예상)이 듭니다.

## 문제가 생기면

- **화면이 안 열려요**: 명령 프롬프트에 `npm run dev`가 실행 중인지 확인하고, 주소가 `http://localhost:5173` 인지 확인하세요.
- **`npm install`에서 오류가 나요**: 오류 문구 전체를 복사해서 알려주세요.
- **버튼이 회색이에요**: 조건이 맞지 않는 상태입니다. 버튼에 마우스를 올리면 이유가 나옵니다. (예: 정렬은 2개 이상 선택 필요)
- **상태줄에 '서버 꺼짐'이에요**: `npm run setup`을 했는지, `npm run dev` 창에 오류가 없는지 확인하세요. Python 설치 시 PATH 체크를 빠뜨렸다면 Python을 다시 설치하세요.
- **AI 버튼이 회색이에요**: 연결된 AI가 없습니다. ⚙ AI 설정에서 하나를 연결하세요. (15장)
- **로컬 모델이 느려요**: PC 사양에 비해 모델이 큽니다. qwen3:4b 같은 작은 모델을 쓰거나, AI 설정에서 시간 제한을 늘리세요.
- **뭔가 안 됐어요**: 아래 **작업 로그**의 빨간/노란 줄에 이유가 적혀 있습니다.
