# Phase 2 개발 보고서 — 3D 편집 기능 확장

작성일: 2026-11-05 · 버전 0.2.0

Phase 1의 기능과 코드 구조(명령 기반 Undo/Redo, 편집 엔진 분리)를 그대로 유지하면서 편집 기능을 확장했습니다.
**Phase 1 브라우저 테스트를 수정 없이 다시 실행해 모두 통과**하는 것으로 기존 기능이 망가지지 않았음을 확인했습니다.

## 1. 실행 방법 (기존과 동일)

1. 새 압축 파일을 풀어 기존 `FORM3D` 폴더를 **통째로 바꿉니다** (예: `C:\Users\hayul\Desktop\FORM3D`).
   - 기존 폴더는 이름을 `FORM3D-phase1` 등으로 바꿔 백업해 두면 안전합니다.
2. 명령 프롬프트(또는 PowerShell)에서:
   ```
   cd C:\Users\hayul\Desktop\FORM3D
   npm install
   npm run dev
   ```
3. 브라우저에서 http://localhost:5173 을 엽니다.

## 2. 구현한 기능 (모두 실제 동작, 모두 실행 취소 가능)

### ① OBJ 파일 가져오기
- 상단 **“모델 불러오기”** 버튼(기존 “GLB 불러오기”) 또는 뷰포트에 끌어다 놓기
- `.obj` 단독, 또는 `.obj` + `.mtl` + 텍스처(`.png/.jpg/.jpeg/.webp/.bmp`)를 **함께 선택**
- MTL의 색상·거칠기(Ns)·텍스처(map_Kd 등)를 연결. 하위 폴더 경로(`textures\wood.png`)도 파일 이름으로 찾음
- 재질은 PBR(MeshStandardMaterial)로 변환 → 기존 재질 편집(색상/Metallic/Roughness)과 GLB 내보내기 그대로 사용
- MTL 누락 → 경고 후 기본 회색 재질, 텍스처 누락 → 어떤 파일이 없는지 경고 (콘솔 오류 없음)
- 빈 파일·바이너리 파일·정점 없는 파일은 이유와 함께 거부

### ② 복제 · 여러 오브젝트 선택
- **Ctrl+클릭 / Shift+클릭**: 뷰포트에서 여러 개 선택(다시 클릭하면 해제), 씬 계층에서는 Shift+클릭이 범위 선택
- **Ctrl+A** 전체 선택, **Esc** 선택 해제. 마지막에 선택한 것이 “활성” 오브젝트(보라색 박스), 나머지는 파란색 박스
- **Ctrl+D** 복제 (계층 패널 버튼·우클릭 메뉴·속성 패널 버튼으로도 가능)
  - 복제본은 원본 옆(+X)에 놓이고, 이름은 `Box.001`, `Box.002` …
  - 재질은 원본과 독립 (복제본 색을 바꿔도 원본 유지), 하위 계층 전체 복제
  - 애니메이션/스킨 모델도 뼈대 연결까지 올바르게 복제
- 여러 개 삭제도 Delete 한 번, Ctrl+Z 한 번으로 모두 복원(선택 상태 포함)

### ③ 그룹화 · 그룹 해제
- **Ctrl+G** 그룹으로 묶기: 그룹 원점은 선택 영역의 중심, 각 오브젝트의 보이는 위치는 그대로
- **Ctrl+Shift+G** 그룹 해제: 그룹을 회전/크기 변경한 상태여도 자식들의 보이는 위치·회전·크기 유지
- 그룹이 아닌 메시, 애니메이션/뼈대가 있는 모델은 그룹 해제를 거부하고 이유를 로그에 표시 (애니메이션 보호)

### ④ 정밀한 위치·회전·크기 조절 (오른쪽 Transform 패널)
- **수식 입력**: `(1+2)*1.5`, `10/4` 등 (안전한 자체 계산기, eval 미사용)
- **↑/↓ 키**로 증감 (Shift ×10, Alt ×0.1)
- **X/Y/Z 글자를 좌우로 드래그**해 값 조절 → 드래그 1회 = 실행 취소 1회
- 항목별 **초기화 버튼**(위치 0, 회전 0, 크기 1), **크기 비율 고정**
- 여러 개 선택 시 입력한 값이 모두에 적용. 값이 서로 다르면 `—`로 표시
- 잘못된 입력은 무시하고 이전 값으로 복원

### ⑤ 이동·회전·크기 도구 개선 (뷰포트 기즈모)
- 여러 개 선택 시 **선택 중심에 기즈모**가 생기고, 이동/회전/크기가 모두에 함께 적용 (중심 기준 회전)
- 드래그 중 화면 위쪽에 **실시간 변화량 표시** (예: `이동 Δ X 0.5 Y 0 Z 0`, `회전 45°`)
- 드래그 1회 = 실행 취소 1회, 드래그 후에도 선택 유지

### ⑥ 정렬 · 스냅
- 뷰포트 도구 모음의 **자석 버튼**: 스냅 켜기/끄기, 옆의 숫자를 눌러 단위 설정(이동 m, 회전 °, 크기)
- 스냅 상태에서 **Ctrl을 누른 채 드래그**하면 일시적으로 스냅 해제(반대로 꺼져 있으면 일시 적용)
- 오른쪽 **정렬 / 스냅** 패널
  - X/Y/Z × 최소/중앙/최대 정렬 (2개 이상), 기준: 선택 영역 전체 또는 활성 오브젝트
  - X/Y/Z 균등 분배 (3개 이상)
  - **바닥에 놓기**(바닥면을 Y=0에), **그리드 스냅**(위치를 스냅 단위에 맞춤)
  - 조건이 맞지 않으면 버튼이 비활성화되고 이유를 툴팁으로 안내

### ⑦ 카메라 시점 프리셋
- 숫자 키: **1 정면 · 2 뒷면 · 3 오른쪽 · 4 왼쪽 · 5 위 · 6 아래 · 0 등각** (숫자패드도 동작)
- 뷰포트 도구 모음의 **카메라 버튼** 메뉴에서도 선택
- 부드럽게 회전하며, 보고 있던 중심과 거리는 유지 (F로 대상에 맞추기와 함께 사용)

### ⑧ 씬 계층 구조 개선
- **드래그 앤 드롭**: 행 가운데에 놓으면 하위로, 위/아래 가장자리에 놓으면 순서 변경, 빈 영역에 놓으면 최상위로
  - 보이는 위치는 그대로 유지, 여러 개 선택해 함께 이동 가능, 자기 하위로 넣는 것은 자동으로 막음
- **더블클릭 / F2**: 이름 바꾸기 (Enter 확정, Esc 취소)
- **우클릭 메뉴**: 이름 바꾸기, 복제, 그룹으로 묶기, 그룹 해제, 최상위로 꺼내기, 카메라 맞추기, 숨기기, 삭제
- **이름 검색**, **모두 펼치기 / 접기**, 접힌 그룹의 자식 수 표시
- **↑↓ 키**로 이동, **←→**로 접기/펼치기
- 선택한 항목은 자동으로 펼쳐지고 스크롤됨

### 그 밖의 개선
- GLB를 다시 불러올 때 이름의 `.`이 사라지던 문제(`Box.001` → `Box001`) 수정 (애니메이션이 없는 모델)
- 복제된 애니메이션 모델을 내보낼 때 같은 애니메이션 클립이 중복 저장되지 않게 수정
- 하단 상태 표시줄에 선택 개수 표시 (`선택: Cone 외 3개`)

Phase 2 브라우저 테스트가 확인하는 것 (기능별):
1. OBJ+MTL+텍스처 불러오기, 재질 변환·편집, 누락 경고, 잘못된 파일 거부, OBJ→GLB 왕복
2. Ctrl/Shift 다중 선택(계층·뷰포트), Ctrl+A
3. 복제 위치·이름·재질 독립·Undo/Redo·선택 복원
4. 그룹화/해제 시 월드 위치 유지, 그룹 이동, 해제 거부 안내
5. 혼합 값 표시, 다중 적용, 수식, ↑↓, 회전, 비율 고정, 초기화, 축 드래그 + Undo
6. 다중 기즈모 이동·회전(중심 기준), 실시간 표시, 스냅, Ctrl 일시 해제
7. 정렬(선택 영역/활성 기준), 분배, 바닥에 놓기, 그리드 스냅
8. 시점 7종(키·메뉴), 거리 유지
9. 계층 드래그 앤 드롭(하위/위/아래/최상위/다중), 자기 하위 금지, 검색, 이름 변경, 키보드, 우클릭 메뉴, 접기/펼치기
10. 그룹 계층 GLB 내보내기 → 다시 불러오기 시 구조·이름 보존
11. 애니메이션 모델 복제(뼈대 연결 확인), 일부만 복제·그룹 해제 거부, 내보내기

테스트 중 발견해 고친 문제: 계층 드래그 앤 드롭이 행 위에서 동작하지 않던 버그, 축 드래그 후 Ctrl+Z가 입력칸에 먹히던 문제,
GLB 왕복 시 이름 변경, 오른쪽 패널 입력칸이 좁아 값이 잘리던 문제.

## 4. 미완성 / 이후 단계

| 기능 | 상태 |
| --- | --- |
| 뷰포트 드래그로 사각형 영역 선택 | 미구현 (Ctrl/Shift+클릭, Ctrl+A로 대체) |
| 직교(Orthographic) 카메라 | 미구현 — 시점 프리셋은 원근 카메라로 동작 |
| 기즈모 기준점 선택(개별 원점, 3D 커서) | 미구현 — 여러 개 선택 시 선택 중심 기준 |
| 정점/표면 스냅 | 미구현 — 그리드·단위 스냅만 지원 |
| 여러 오브젝트 재질 동시 편집 | 미구현 — 재질은 1개 선택 시 편집 |
| 복사/붙여넣기 (Ctrl+C/V) | 미구현 — 복제(Ctrl+D) 사용 |
| OBJ 내보내기, FBX/STL 불러오기 | 미구현 — 내보내기는 GLB. 새 형식은 `io/import.ts`에 로더만 추가하면 연결 |
| OBJ의 TGA 텍스처 | 미지원 — PNG/JPG/WEBP/BMP만 |
| 저장(Phase 3), AI 편집(Phase 4), 모델 생성(Phase 5) | 기존과 같이 비활성 + 단계 표시 |

알려진 제한
- 회전된 그룹 안의 오브젝트를 여러 개 선택해 **한 축만** 크기 조절하면, 수학적으로 기울어짐(전단)이 생길 수 있어 가장 가까운 값으로 근사합니다.
- 애니메이션 모델의 일부(뼈대, 스킨 메시, 하위 노드)는 따로 복제·그룹·계층 이동할 수 없습니다 (애니메이션이 깨지지 않도록 막음). 모델 전체는 가능합니다.
- 복제본은 지오메트리(형상 데이터)를 원본과 공유해 메모리를 아낍니다. Phase 4 이후 형상 편집 기능을 넣을 때 편집 직전에 분리하도록 설계해야 합니다.

## 5. 확장성을 위한 구조

- 모든 새 기능은 **명령(Command)** 으로 구현 → Undo/Redo, 작업 내역, Phase 4 AI 명령이 같은 경로를 사용
  - 새 명령: `DuplicateObject`, `GroupObjects`, `UngroupObject`, `ReparentObject`, `AlignObjects` (AI 허용 명령 목록에도 추가)
  - `CompositeCommand`: 여러 명령을 실행 취소 1회 단위로 묶고 선택 상태도 복원, 중간 실패 시 자동 되돌림
- 정렬·분배·스냅 계산은 UI와 분리된 순수 함수(`packages/editor-core/src/align.ts`) → AI나 스크립트에서 그대로 재사용
- 파일 불러오기는 확장자별 로더 선택(`io/import.ts`) → 새 형식 추가가 쉬움
- 선택은 엔진이 관리하며 Phase 1 API(`getSelected`, `select`)와 호환
